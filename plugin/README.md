# SellerSheet Skills

Run your Amazon business by talking to your AI — orders and settlements, bulk listing edits,
FBA shipments, Ads bids and budgets, inventory and search-term reports, compliant listing
images and A+ — across multiple stores and marketplaces, with every result written to Google
Sheets for you to review.

This plugin contains:

- **`skills/`** — the SellerSheet skills (one bundle; they share `skills/sellersheet-shared`).
- **`.mcp.json`** — the hosted SellerSheet MCP server, `https://sellersheetai.com/mcp`. It is a
  remote server: nothing runs locally and no API key is stored. On first use your agent opens a
  browser sign-in (OAuth) to your SellerSheet account; access is limited to the stores you
  connected.

Nothing in this plugin downloads or runs code on your machine.
